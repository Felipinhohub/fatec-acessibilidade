# Projeto base para aula de Acessibilidade
## ALUNO: FELIPE SANTOS NASCIMENTO

## Desafio 2 — Alterar Contraste

Objetivo
Adicionar um botão apra alterar o contraste da tela.


### Algoritmo para adicionar função de alteração de constrate.

- Verificar tons de cores atuais da pagina.
- Verificar na roda de cores quais cores constrtam com as atuais do site.
- Cria um botão com icone amigavel, para ajuste de contraste.
- Posicionar botão proximo as itens de acessibilidade, se já existirem.
- Cria logica para alteração da cor em toda a pagina.
- Aplicar em todo o site o ajuste de contraste ao apertar no botão designado.

- Remover em todo o site o contraste ao aperta o botão caso já ativado.
