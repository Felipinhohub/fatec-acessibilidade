## Desafio 1 — Aumentar/Diminuir Fonte

Objetivo
Melhorar a usabilidade para pessoas com baixa visão.

 Escreva em um papel um algoritmo que permita aumentar ou diminuir o tamanho da letra conforme a preferência do usuário

#### Algoritmo para adicionar função de aumentar ou diminuir fonte.

- Verificar qual elemento irá mudar a fonte.
- Verificar se ele existe.
- Pegar o tamanho atual da fonte.
- Criar limite mínimo (para não ficar muito pequeno)
- Criar limite máximo (para não ficar gigante)
- Criar um botão para aumentar:
- Se ainda não chegou no máximo ainda pode aumentar.
- Criar um botão para diminuir:
- Se ainda não chegou no mínimo ainda pode diminuir.

## Desafio 2 — Alterar Contraste

Objetivo
Adicionar um botão apra alterar o contraste da tela.


### Algoritmo para adicionar função de alteração de constrate.

- Verificar tons de cores atuais da pagina.
- Verificar na roda de cores quais cores constrtam com as atuais do site.
- Cria um botão com icone amigavel, para ajuste de contraste.
- Posicionar botão proximo as itens de acessibilidade, se já existirem.
- Cria logica para alteração da cor em toda a pagina.
- Aplicar em todo o site o ajuste de contraste ao apertar no botão designado.
- Remover em todo o site o contraste ao aperta o botão caso já ativado.
